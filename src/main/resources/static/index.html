网关决策说明

一个请求的完整旅程：准入检查（限流/配额）→ 缓存查找 → 单飞抢加载权 → 候选供应商逐个尝试（含故障转移）→ 回填缓存 → 落库。

每一层都在为后面的层挡掉不该发生的开销： 限流挡过量请求，缓存挡重复请求，路由只处理真正需要上游的请求。
